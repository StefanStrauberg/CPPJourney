## Задание 1. Угадай число ⭐

> [!task] Условие
> Компьютер загадывает число от 1 до 100, игрок угадывает. После каждой попытки программа подсказывает «больше» или «меньше».
>
> Требования:
> 1. Три уровня сложности: лёгкий (без ограничения попыток), нормальный (10 попыток), сложный (7 попыток).
> 2. Неправильный ввод (буквы вместо числа) не ломает программу и **не считается** попыткой.
> 3. В конце: победа с числом попыток или поражение с раскрытием загаданного числа.
> 4. Предложение сыграть ещё раз (`y`/`n`).
>
> Пример сеанса:
> ```
> Сложность: 1) лёгкая  2) нормальная (10 попыток)  3) сложная (7 попыток)
> > 3
> Я загадал число от 1 до 100. Угадывай!
> Попытка 1: 50
> Меньше!
> Попытка 2: 25
> Больше!
> Попытка 3: abc
> Это не число.
> Попытка 3: 37
> Угадал! Попыток: 3
> Ещё раз? (y/n): n
> ```

> [!hint]- Подсказка
> - Генератор (`std::mt19937`) и распределение создай **до** цикла «сыграть ещё раз», один раз на всю программу.
> - Ограничение попыток удобно хранить числом, где `0` означает «без ограничения»: `while (maxAttempts == 0 || attempts < maxAttempts)`.
> - Защита от неправильного ввода — из [[01.6 Ввод, вывод, строки и случайность#Что если ввели не число|урока 01.6]]. Если чтение не удалось, сделай `continue`, не увеличивая счётчик попыток.

> [!solution]- Решение
> ```cpp
> #include <iostream>
> #include <limits>
> #include <print>
> #include <random>
>
> int main() {
>     std::random_device seedSource;
>     std::mt19937 rng(seedSource());
>     std::uniform_int_distribution<int> secretDist(1, 100);
>
>     bool playAgain = true;
>     while (playAgain) {
>         // ---------- выбор сложности ----------
>         std::println("Сложность: 1) лёгкая  2) нормальная (10 попыток)  3) сложная (7 попыток)");
>         std::print("> ");
>         int difficulty = 0;
>         while (!(std::cin >> difficulty) || difficulty < 1 || difficulty > 3) {
>             if (std::cin.eof()) {
>                 return 0;
>             }
>             std::cin.clear();
>             std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
>             std::print("Введи 1, 2 или 3: ");
>         }
>
>         int maxAttempts = 0;    // 0 — без ограничения
>         if (difficulty == 2) {
>             maxAttempts = 10;
>         } else if (difficulty == 3) {
>             maxAttempts = 7;
>         }
>
>         // ---------- сама игра ----------
>         const int secret = secretDist(rng);
>         int attempts = 0;
>         bool won = false;
>
>         std::println("Я загадал число от 1 до 100. Угадывай!");
>         while (maxAttempts == 0 || attempts < maxAttempts) {
>             std::print("Попытка {}: ", attempts + 1);
>             int guess = 0;
>             if (!(std::cin >> guess)) {
>                 if (std::cin.eof()) {
>                     return 0;
>                 }
>                 std::cin.clear();
>                 std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
>                 std::println("Это не число.");
>                 continue;    // неудачный ввод не считается попыткой
>             }
>             ++attempts;
>
>             if (guess < secret) {
>                 std::println("Больше!");
>             } else if (guess > secret) {
>                 std::println("Меньше!");
>             } else {
>                 won = true;
>                 break;
>             }
>         }
>
>         if (won) {
>             std::println("Угадал! Попыток: {}", attempts);
>         } else {
>             std::println("Попытки кончились. Я загадал {}.", secret);
>         }
>
>         // ---------- ещё раз? ----------
>         std::print("Ещё раз? (y/n): ");
>         char answer = 'n';
>         std::cin >> answer;
>         playAgain = (answer == 'y' || answer == 'Y');
>     }
> }
> ```
>
> **Почему именно 7 попыток на сложном уровне?** Если каждый раз называть середину оставшегося диапазона (50, потом 25 или 75 и т.д.), диапазон уменьшается вдвое. 100 → 50 → 25 → 13 → 7 → 4 → 2 → 1: семи попыток **всегда** хватает. Это **двоичный поиск**, и его сложность — log₂(n): для миллиона чисел хватит 20 попыток. Мы ещё не раз встретимся с ним в курсе.

## Задание 2. Бюджет кадра ⭐

> [!task] Условие
> Напиши программу, которая печатает таблицу для частот кадров 30, 60, 75, 120, 144 и 240 FPS:
> - время одного кадра в миллисекундах (2 знака после запятой);
> - сколько кадров приходится на одну минуту;
> - сколько игровых объектов можно обновить за кадр, если на логику отдаём **25%** бюджета кадра, а обновление одного объекта стоит **2 микросекунды** (0,002 мс).
>
> Таблица должна быть ровной:
> ```
>   FPS |   мс/кадр |   кадров/мин |   объектов в 25%
> ------+-----------+--------------+-----------------
>    30 |     33.33 |         1800 |             4166
>    60 |     16.67 |         3600 |             2083
>   ...
> ```

> [!hint]- Подсказка
> - Значения FPS удобно положить в `constexpr std::array<int, 6>` и пройти циклом `for` по диапазону.
> - Время кадра: `1000.0 / fps`. Обрати внимание на `1000.0`: с `1000` получилось бы целочисленное деление.
> - Ширина колонок: `{:>9.2f}` — выравнивание вправо, ширина 9, два знака. Строку из дефисов можно получить через `{:-<5}` с пустой строкой `""` в качестве аргумента.

> [!solution]- Решение
> ```cpp
> #include <array>
> #include <print>
>
> int main() {
>     constexpr std::array<int, 6> fpsValues = {30, 60, 75, 120, 144, 240};
>     constexpr double costPerObjectMs = 0.002;   // 2 микросекунды на объект
>     constexpr double logicShare = 0.25;         // логике отдаём четверть кадра
>
>     std::println("{:>5} | {:>9} | {:>12} | {:>16}", "FPS", "мс/кадр", "кадров/мин", "объектов в 25%");
>     std::println("{:-<5}-+-{:-<9}-+-{:-<12}-+-{:-<16}", "", "", "", "");
>
>     for (int fps : fpsValues) {
>         double frameMs = 1000.0 / fps;
>         int framesPerMinute = fps * 60;
>         int objects = static_cast<int>(frameMs * logicShare / costPerObjectMs);
>         std::println("{:>5} | {:>9.2f} | {:>12} | {:>16}", fps, frameMs, framesPerMinute, objects);
>     }
> }
> ```
>
> Посмотри на последнюю колонку: при 240 FPS на логику остаётся в 8 раз меньше объектов, чем при 30. Отсюда вечная борьба за микросекунды в движках, и отсюда же идея **фиксированного шага логики**: физику и ИИ обновляют, например, 30 или 60 раз в секунду **независимо** от частоты отрисовки. Мы реализуем это в модуле 15.

## Задание 3. Арена ⭐⭐

> [!task] Условие
> Пошаговый бой с монстром.
>
> **Монстр** выбирается случайно из списка (структура `Monster` с полями: имя, здоровье, минимальный и максимальный урон). Например: Imp (60 HP, урон 4–9), Pinky (90 HP, 6–12), Baron (140 HP, 8–16).
>
> **Игрок**: 100 HP, 3 зелья. Каждый ход выбирает действие:
> 1. **Атака**: урон 8–15, с шансом 15% критический (×2).
> 2. **Защита**: урон монстра в этот ход уменьшается вдвое.
> 3. **Зелье**: +30 HP, но не выше максимума. Если зелий нет, ход потерян.
>
> **Монстр** отвечает ударом со случайным уроном из своего диапазона. Если у него осталось меньше 30% здоровья, с вероятностью 50% он впадает в **ярость**: урон ×1,5.
>
> Каждый ход выводи полоски здоровья: `[##########----------]`.
> В конце: победа или поражение, число ходов и суммарный нанесённый урон.
>
> ⭐ Бонус: раскрась вывод (критический удар жёлтым, ярость красным, победа зелёным) управляющими последовательностями из [[01.6 Ввод, вывод, строки и случайность#Управление консолью — цвета и очистка экрана|урока 01.6]].

> [!hint]- Подсказка
> - Список монстров: `std::vector<Monster> bestiary = { {"Imp", 60, 4, 9}, ... };`, а случайный индекс — от `0` до `bestiary.size() - 1`.
> - **Скопируй** выбранного монстра в отдельную переменную: `Monster monster = bestiary[index];`. Тогда урон по нему не испортит «справочник».
> - Длина полоски: `health * 20 / maxHealth` символов `#`, а остальное дополнит формат `{:-<20}`.
> - Проверка «меньше 30%» без дробей: `monster.health * 100 < maxHealth * 30`.
> - `std::min` из `<algorithm>` поможет не вылечиться выше максимума.

> [!solution]- Решение
> ```cpp
> #include <algorithm>
> #include <iostream>
> #include <limits>
> #include <print>
> #include <random>
> #include <string>
> #include <vector>
>
> struct Monster {
>     std::string name;
>     int health = 0;
>     int minDamage = 0;
>     int maxDamage = 0;
> };
>
> int main() {
>     std::random_device seedSource;
>     std::mt19937 rng(seedSource());
>
>     const std::vector<Monster> bestiary = {
>         {"Imp", 60, 4, 9},
>         {"Pinky", 90, 6, 12},
>         {"Baron", 140, 8, 16},
>     };
>     std::uniform_int_distribution<int> pickMonster(0, static_cast<int>(bestiary.size()) - 1);
>     Monster monster = bestiary[pickMonster(rng)];   // копия из справочника
>     const int monsterMaxHealth = monster.health;
>
>     constexpr int playerMaxHealth = 100;
>     int playerHealth = playerMaxHealth;
>     int potions = 3;
>
>     std::uniform_int_distribution<int> playerDamage(8, 15);
>     std::uniform_int_distribution<int> monsterDamage(monster.minDamage, monster.maxDamage);
>     std::bernoulli_distribution critical(0.15);
>     std::bernoulli_distribution rage(0.5);
>
>     int turn = 0;
>     int totalDealt = 0;
>
>     std::println("На арену выходит {}! Здоровье: {}", monster.name, monster.health);
>
>     while (playerHealth > 0 && monster.health > 0) {
>         ++turn;
>
>         // ---------- состояние ----------
>         int playerBar = playerHealth * 20 / playerMaxHealth;
>         int monsterBar = monster.health * 20 / monsterMaxHealth;
>         std::println("\n--- Ход {} ---", turn);
>         std::println("Ты     [{:-<20}] {:3}/{}  зелий: {}",
>                      std::string(playerBar, '#'), playerHealth, playerMaxHealth, potions);
>         std::println("{:<6} [{:-<20}] {:3}/{}",
>                      monster.name, std::string(monsterBar, '#'), monster.health, monsterMaxHealth);
>
>         // ---------- ход игрока ----------
>         std::print("1) атака  2) защита  3) зелье > ");
>         int action = 0;
>         while (!(std::cin >> action) || action < 1 || action > 3) {
>             if (std::cin.eof()) {
>                 return 0;
>             }
>             std::cin.clear();
>             std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
>             std::print("Выбери 1, 2 или 3 > ");
>         }
>
>         bool defending = false;
>         if (action == 1) {
>             int damage = playerDamage(rng);
>             if (critical(rng)) {
>                 damage *= 2;
>                 std::println("\x1b[33mКРИТИЧЕСКИЙ УДАР!\x1b[0m");
>             }
>             monster.health -= damage;
>             totalDealt += damage;
>             std::println("Ты наносишь {} урона.", damage);
>         } else if (action == 2) {
>             defending = true;
>             std::println("Ты поднимаешь щит.");
>         } else if (potions > 0) {
>             --potions;
>             int healed = std::min(30, playerMaxHealth - playerHealth);
>             playerHealth += healed;
>             std::println("Ты выпиваешь зелье: +{} здоровья.", healed);
>         } else {
>             std::println("Зелья кончились! Ход потерян.");
>         }
>
>         if (monster.health <= 0) {
>             break;
>         }
>
>         // ---------- ход монстра ----------
>         int damage = monsterDamage(rng);
>         if (monster.health * 100 < monsterMaxHealth * 30 && rage(rng)) {
>             damage = damage * 3 / 2;
>             std::println("\x1b[31m{} впадает в ярость!\x1b[0m", monster.name);
>         }
>         if (defending) {
>             damage /= 2;
>         }
>         playerHealth -= damage;
>         std::println("{} бьёт тебя на {} урона.", monster.name, damage);
>     }
>
>     std::println("");
>     if (playerHealth > 0) {
>         std::println("\x1b[32mПобеда!\x1b[0m {} повержен за {} ходов. Нанесено урона: {}.",
>                      monster.name, turn, totalDealt);
>     } else {
>         std::println("\x1b[31mПоражение.\x1b[0m {} оказался сильнее. Ходов продержался: {}.",
>                      monster.name, turn);
>     }
> }
> ```
>
> **Разбор.** Обрати внимание на `damage * 3 / 2` вместо `damage * 1.5`: в целых числах сначала умножаем, потом делим, чтобы не потерять точность (и не связываться с `double` → `int`). А ещё на длину `main`: больше 100 строк, и куски вроде «прочитать число от 1 до 3» и «нарисовать полоску» хочется вынести отдельно. Именно это мы сделаем в модуле 02.

## Задание 4. Цвета и флаги ⭐⭐

> [!task] Условие
> **Часть 1. Цвета.** Есть два цвета в формате `0xRRGGBBAA`: лава `0xFF6A00FF` и вода `0x1E90FFFF`. Для каждого:
> - распакуй компоненты R, G, B, A и выведи их;
> - вычисли **яркость** (оттенок серого) по формуле `0.299·R + 0.587·G + 0.114·B` и собери из неё серый цвет (R = G = B = яркость, A = 255);
> - вычисли цвет **вдвое темнее**: R, G и B сдвигом вправо на 1, alpha без изменений.
>
> Наконец, **смешай** лаву и воду пополам (среднее по каждому каналу).
>
> Выводи цвета в hex, а рядом — цветной квадратик. Терминал умеет 24-битный цвет фона: `\x1b[48;2;R;G;Bm` и затем несколько пробелов, и `\x1b[0m` для сброса.
>
> **Часть 2. Флаги состояния.** Пять флагов персонажа: `OnGround`, `InWater`, `Poisoned`, `Burning`, `Stunned`. Опиши события **списком данных**: структура `Event` с текстом и двумя масками (какие флаги установить, какие сбросить), а потом примени события по очереди. После каждого печатай флаги в двоичном виде и названия активных эффектов:
> ```
> Спрыгнул на землю                        00001: OnGround
> Наступил в ядовитую лужу                 00111: OnGround InWater Poisoned
> Подорвался на бочке                      11111: OnGround InWater Poisoned Burning Stunned
> Пришёл в себя                            01111: OnGround InWater Poisoned Burning
> ```

> [!hint]- Подсказка
> - Распаковка компоненты: `(color >> 24) & 0xFF` и т.д. Упаковка: `(r << 24) | (g << 16) | (b << 8) | a` (всё в `std::uint32_t`).
> - Яркость считай в `double`, а потом приведи к целому через `static_cast`.
> - Названия флагов положи в `std::array<std::string, 5>` в том же порядке, что и биты. Тогда «имя бита номер `i`» — это просто `names[i]`, а проверка бита — `(state & (1u << i)) != 0`.

> [!solution]- Решение
> ```cpp
> #include <array>
> #include <cstdint>
> #include <print>
> #include <string>
> #include <vector>
>
> constexpr std::uint32_t FlagOnGround = 1u << 0;
> constexpr std::uint32_t FlagInWater  = 1u << 1;
> constexpr std::uint32_t FlagPoisoned = 1u << 2;
> constexpr std::uint32_t FlagBurning  = 1u << 3;
> constexpr std::uint32_t FlagStunned  = 1u << 4;
>
> struct Event {
>     std::string description;
>     std::uint32_t set = 0;      // какие флаги установить
>     std::uint32_t clear = 0;    // какие флаги сбросить
> };
>
> int main() {
>     // ================= Часть 1: цвета =================
>     const std::array<std::uint32_t, 2> colors = {0xFF6A00FF, 0x1E90FFFF};
>     const std::array<std::string, 2> colorNames = {"Лава", "Вода"};
>
>     for (int i = 0; i < 2; ++i) {
>         std::uint32_t c = colors[i];
>         std::uint32_t r = (c >> 24) & 0xFF;
>         std::uint32_t g = (c >> 16) & 0xFF;
>         std::uint32_t b = (c >> 8) & 0xFF;
>         std::uint32_t a = c & 0xFF;
>
>         auto luma = static_cast<std::uint32_t>(0.299 * r + 0.587 * g + 0.114 * b);
>         std::uint32_t gray = (luma << 24) | (luma << 16) | (luma << 8) | 0xFF;
>         std::uint32_t dark = ((r >> 1) << 24) | ((g >> 1) << 16) | ((b >> 1) << 8) | a;
>
>         std::println("{}: {:#010x}  R={} G={} B={} A={}", colorNames[i], c, r, g, b, a);
>         std::println("  исходный \x1b[48;2;{};{};{}m      \x1b[0m", r, g, b);
>         std::println("  серый    \x1b[48;2;{};{};{}m      \x1b[0m {:#010x}", luma, luma, luma, gray);
>         std::println("  темнее   \x1b[48;2;{};{};{}m      \x1b[0m {:#010x}", r >> 1, g >> 1, b >> 1, dark);
>     }
>
>     // Смешивание пополам: среднее по каждому каналу
>     std::uint32_t mixed = 0;
>     for (int shift = 24; shift >= 0; shift -= 8) {
>         std::uint32_t channel1 = (colors[0] >> shift) & 0xFF;
>         std::uint32_t channel2 = (colors[1] >> shift) & 0xFF;
>         mixed |= ((channel1 + channel2) / 2) << shift;
>     }
>     std::println("Смесь: {:#010x} \x1b[48;2;{};{};{}m      \x1b[0m\n",
>                  mixed, (mixed >> 24) & 0xFF, (mixed >> 16) & 0xFF, (mixed >> 8) & 0xFF);
>
>     // ================= Часть 2: флаги =================
>     const std::array<std::string, 5> flagNames = {"OnGround", "InWater", "Poisoned", "Burning", "Stunned"};
>
>     const std::vector<Event> events = {
>         {"Спрыгнул на землю", FlagOnGround, 0},
>         {"Наступил в ядовитую лужу", FlagInWater | FlagPoisoned, 0},
>         {"Подорвался на бочке", FlagBurning | FlagStunned, 0},
>         {"Пришёл в себя", 0, FlagStunned},
>         {"Нырнул, огонь потух", 0, FlagBurning | FlagOnGround},
>         {"Выпил антидот и выбрался на берег", FlagOnGround, FlagPoisoned | FlagInWater},
>     };
>
>     std::uint32_t state = 0;
>     for (const Event& e : events) {
>         state |= e.set;
>         state &= ~e.clear;
>
>         std::print("{:<40} {:05b}:", e.description, state);
>         for (int bit = 0; bit < 5; ++bit) {
>             if ((state & (1u << bit)) != 0) {
>                 std::print(" {}", flagNames[bit]);
>             }
>         }
>         std::println("");
>     }
> }
> ```
>
> **Почему события — это данные.** Мы не написали шесть кусков кода «установи такой-то флаг», а описали события **таблицей** и обработали её одним циклом. Добавить седьмое событие — одна строка. Этот подход называется **data-driven design** («управление данными»), и на нём построены движки: поведение задаётся не кодом, а данными (уровнями, таблицами, конфигами), которые могут менять дизайнеры без программиста.

## Задание 5. «Жизнь» Конвея ⭐⭐⭐

> [!task] Условие
> Клеточный автомат «Жизнь» придумал математик Джон Конвей в 1970 году. Поле — сетка клеток, каждая живая или мёртвая. Каждое поколение все клетки **одновременно** обновляются по правилам:
> - живая клетка с 2 или 3 живыми соседями **выживает**, иначе умирает;
> - мёртвая клетка ровно с 3 живыми соседями **оживает**.
>
> Соседи — 8 окружающих клеток. Поле **замкнуто в тор**: правый край соседствует с левым, верхний с нижним.
>
> Требования:
> 1. Поле 40 × 20, начальное заполнение случайное (25% живых).
> 2. Анимация: 300 поколений, каждое рисуется на месте предыдущего, пауза 80 мс.
> 3. Под полем — номер поколения и население (число живых клеток).
>
> Живую клетку рисуй двумя символами `██` (тогда клетки выглядят квадратными), мёртвую — двумя пробелами.

> [!hint]- Подсказка 1: структура
> - Поле: `std::array<std::array<bool, width>, height>`. Для удобства заведи псевдоним: `using Grid = std::array<std::array<bool, width>, height>;`.
> - Новое поколение считай в **отдельном** массиве `next`, а потом присвой `grid = next;`. Если обновлять клетки на месте, соседи будут считаться частично по новому поколению, и правила нарушатся.
> - Соседи с замыканием в тор: `int nx = (x + dx + width) % width;`. Прибавление `width` защищает от отрицательного остатка при `x + dx == -1` (помнишь [[01.3 Операторы, выражения и преобразования#Деление отрицательных чисел|урок 01.3]]?).

> [!hint]- Подсказка 2: анимация
> - Пауза: `std::this_thread::sleep_for(std::chrono::milliseconds(80));` из заголовков `<thread>` и `<chrono>`.
> - Перед началом очисти экран `\x1b[2J`, а каждый кадр начинай с `\x1b[H` (курсор в левый верхний угол): кадр нарисуется поверх предыдущего, без мерцания.
> - Собирай весь кадр в одну `std::string` и печатай одним вызовом. Тысяча мелких `print` — это тысяча обращений к консоли, и анимация будет дёргаться.
> - `\x1b[?25l` прячет курсор, `\x1b[?25h` возвращает его.

> [!solution]- Решение
> ```cpp
> #include <array>
> #include <chrono>
> #include <format>
> #include <print>
> #include <random>
> #include <string>
> #include <thread>
>
> int main() {
>     constexpr int width = 40;
>     constexpr int height = 20;
>     constexpr int generations = 300;
>
>     using Grid = std::array<std::array<bool, width>, height>;
>     Grid grid{};
>
>     std::mt19937 rng(std::random_device{}());
>     std::bernoulli_distribution aliveChance(0.25);
>     for (auto& row : grid) {
>         for (bool& cell : row) {
>             cell = aliveChance(rng);
>         }
>     }
>
>     std::print("\x1b[2J\x1b[?25l");   // очистить экран, спрятать курсор
>
>     for (int generation = 0; generation < generations; ++generation) {
>         // ---------- рисуем кадр ----------
>         std::string frame = "\x1b[H";
>         int population = 0;
>         for (const auto& row : grid) {
>             for (bool cell : row) {
>                 frame += cell ? "██" : "  ";
>                 population += cell ? 1 : 0;
>             }
>             frame += '\n';
>         }
>         frame += std::format("Поколение {:4}   Население {:4}\n", generation, population);
>         std::print("{}", frame);
>
>         // ---------- считаем следующее поколение ----------
>         Grid next{};
>         for (int y = 0; y < height; ++y) {
>             for (int x = 0; x < width; ++x) {
>                 int neighbors = 0;
>                 for (int dy = -1; dy <= 1; ++dy) {
>                     for (int dx = -1; dx <= 1; ++dx) {
>                         if (dx == 0 && dy == 0) {
>                             continue;   // сама клетка — не сосед
>                         }
>                         int nx = (x + dx + width) % width;
>                         int ny = (y + dy + height) % height;
>                         if (grid[ny][nx]) {
>                             ++neighbors;
>                         }
>                     }
>                 }
>                 next[y][x] = grid[y][x] ? (neighbors == 2 || neighbors == 3) : (neighbors == 3);
>             }
>         }
>         grid = next;   // std::array копируется целиком одним присваиванием
>
>         std::this_thread::sleep_for(std::chrono::milliseconds(80));
>     }
>
>     std::print("\x1b[?25h");   // вернуть курсор
> }
> ```
>
> **Что посмотреть.** Запусти несколько раз: из случайного «шума» рождаются устойчивые фигуры (блоки, мигалки) и **глайдеры** — пятиклеточные фигуры, которые ползут по диагонали через всё поле. Сложное поведение из трёх простых правил — хорошая метафора для игрового ИИ и симуляций.
>
> **Две ловушки, которые ты обошёл.**
> 1. Двойной буфер (`grid` и `next`) — тот же приём, что у видеокарт: кадр рисуется в невидимый буфер, а потом буферы меняются местами. В модуле 07 мы применим его к настоящему окну.
> 2. Если бы поле было `std::vector<std::vector<bool>>`, цикл `for (bool& cell : row)` **не скомпилировался бы**. `std::vector<bool>` — исторически неудачная специализация: она упаковывает значения по одному биту, и ссылку на отдельный бит взять нельзя. В движках вместо него используют `std::vector<char>` или `std::vector<std::uint8_t>`.

## Задание 6. Генератор пещер ⭐⭐⭐

> [!task] Условие
> Сгенерируй карту пещеры алгоритмом **«пьяного шахтёра»** (drunkard's walk), одним из простейших алгоритмов процедурной генерации, которым пользуются настоящие рогалики:
> 1. Карта 60 × 22, изначально целиком из стен `#`.
> 2. «Шахтёр» стартует в центре. На каждом шаге он идёт в случайную из четырёх сторон и превращает клетку в пол `.`. Выходить на крайние клетки (рамку карты) он не может.
> 3. Он копает, пока пол не займёт **40%** площади карты.
> 4. В стартовой клетке ставится игрок `@`, а выход `>` — в **самой дальней** от старта клетке пола (по прямой).
> 5. На 10 случайных клетках пола лежат сокровища `$`.
> 6. Программа спрашивает **зерно** генератора. Одинаковое зерно — одинаковая пещера.
>
> Раскрась карту: стены тёмно-серым (`\x1b[90m`), игрок жёлтым, выход зелёным, сокровища ярко-жёлтым. В конце выведи статистику: сколько шагов сделал шахтёр.

> [!hint]- Подсказка
> - Карта: `std::vector<std::string> map(height, std::string(width, '#'));` — `height` строк по `width` символов `#`.
> - Направления удобно выбирать `switch` по числу из `std::uniform_int_distribution<int>(0, 3)`.
> - Шахтёр не выходит на рамку: шаг влево разрешён, только если `x > 1`, вправо — если `x < width - 2`.
> - Самая дальняя клетка: обойди всю карту двойным циклом и запомни клетку пола с максимальным квадратом расстояния `dx * dx + dy * dy` (корень извлекать не нужно: квадраты сравниваются так же, как сами расстояния).
> - Для раскраски проще печатать карту посимвольно и перед каждым символом выбирать цвет через `switch`.

> [!solution]- Решение
> ```cpp
> #include <iostream>
> #include <print>
> #include <random>
> #include <string>
> #include <vector>
>
> int main() {
>     constexpr int width = 60;
>     constexpr int height = 22;
>     constexpr double floorShare = 0.40;
>     constexpr int treasureCount = 10;
>
>     // ---------- зерно ----------
>     std::print("Зерно пещеры (число): ");
>     unsigned int seed = 0;
>     if (!(std::cin >> seed)) {
>         seed = std::random_device{}();
>         std::println("Не число. Беру случайное зерно {}", seed);
>     }
>     std::mt19937 rng(seed);
>     std::uniform_int_distribution<int> direction(0, 3);
>
>     // ---------- копаем ----------
>     std::vector<std::string> map(height, std::string(width, '#'));
>     const int startX = width / 2;
>     const int startY = height / 2;
>     const int target = static_cast<int>(width * height * floorShare);
>
>     int x = startX;
>     int y = startY;
>     int carved = 0;
>     int steps = 0;
>     while (carved < target) {
>         if (map[y][x] == '#') {
>             map[y][x] = '.';
>             ++carved;
>         }
>         switch (direction(rng)) {
>             case 0: if (x > 1)          { --x; } break;
>             case 1: if (x < width - 2)  { ++x; } break;
>             case 2: if (y > 1)          { --y; } break;
>             case 3: if (y < height - 2) { ++y; } break;
>         }
>         ++steps;
>     }
>
>     // ---------- выход: самая дальняя клетка пола ----------
>     int exitX = startX;
>     int exitY = startY;
>     int bestDistance = 0;
>     for (int cy = 0; cy < height; ++cy) {
>         for (int cx = 0; cx < width; ++cx) {
>             if (map[cy][cx] != '.') {
>                 continue;
>             }
>             int dx = cx - startX;
>             int dy = cy - startY;
>             int distance = dx * dx + dy * dy;   // квадрат расстояния
>             if (distance > bestDistance) {
>                 bestDistance = distance;
>                 exitX = cx;
>                 exitY = cy;
>             }
>         }
>     }
>     map[startY][startX] = '@';
>     map[exitY][exitX] = '>';
>
>     // ---------- сокровища ----------
>     std::uniform_int_distribution<int> randomX(1, width - 2);
>     std::uniform_int_distribution<int> randomY(1, height - 2);
>     int placed = 0;
>     while (placed < treasureCount) {
>         int tx = randomX(rng);
>         int ty = randomY(rng);
>         if (map[ty][tx] == '.') {
>             map[ty][tx] = '$';
>             ++placed;
>         }
>     }
>
>     // ---------- вывод ----------
>     std::string frame;
>     for (const std::string& row : map) {
>         for (char cell : row) {
>             switch (cell) {
>                 case '#': frame += "\x1b[90m#"; break;
>                 case '@': frame += "\x1b[33;1m@"; break;
>                 case '>': frame += "\x1b[32;1m>"; break;
>                 case '$': frame += "\x1b[93m$"; break;
>                 default:  frame += "\x1b[0m."; break;
>             }
>         }
>         frame += "\x1b[0m\n";
>     }
>     std::print("{}", frame);
>     std::println("Зерно: {}. Шахтёр сделал {} шагов, чтобы выкопать {} клеток.", seed, steps, carved);
> }
> ```
>
> **Наблюдения.**
> - Шагов получается в разы больше, чем выкопанных клеток: шахтёр «пьяный» и постоянно ходит по уже выкопанному. Это свойство случайного блуждания: оно медленно удаляется от старта (в среднем на √n клеток за n шагов).
> - Введи одно и то же зерно дважды: пещера совпадёт клетка в клетку. Это та самая повторяемость из [[01.6 Ввод, вывод, строки и случайность#Повторяемая случайность|урока 01.6]].
> - Все клетки пола гарантированно связаны (шахтёр шёл непрерывно), поэтому выход всегда достижим. В практикуме модуля 02 мы проверим это алгоритмом **заливки** и превратим пещеру в настоящий рогалик.
