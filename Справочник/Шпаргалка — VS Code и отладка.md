# Шпаргалка — VS Code и отладка

Подробности в уроках [[00.5 Проект курса в VS Code]] и [[00.6 Отладчик — главный инструмент]].

## Сборка и запуск (CMake Tools)

| Клавиши | Действие |
|---|---|
| `F7` | Собрать проект |
| `Shift+F7` | Собрать выбранную цель |
| `Ctrl+Shift+F5` | Запустить выбранную цель без отладки |
| `F5` | Запустить с отладкой (через `launch.json`) |
| `Shift+F5` | Отладка через CMake Tools / **остановить** отладку |

Полезные команды (`Ctrl+Shift+P`):
- **CMake: Select Configure Preset** — выбрать пресет конфигурации;
- **CMake: Select Build Preset** — Debug или Release;
- **CMake: Set Launch/Debug Target** — какую программу запускать;
- **CMake: Delete Cache and Reconfigure** — «выключить и включить»;
- **C/C++: Reset IntelliSense Database** — если IntelliSense ругается на правильный код.

## Отладчик

| Клавиши | Действие |
|---|---|
| `F9` | Поставить или снять точку останова |
| `F5` | Продолжить до следующей точки |
| `F10` | Шаг с обходом (выполнить строку целиком) |
| `F11` | Шаг с заходом (внутрь функции) |
| `Shift+F11` | Шаг с выходом (до конца текущей функции) |
| `Ctrl+Shift+F5` | Перезапуск |
| `Shift+F5` | Остановить |

- **Условная точка останова**: правый клик по точке → **Edit Breakpoint…** → Expression (`wave == 7`) или Hit Count.
- **Точка журнала**: правый клик слева от номера строки → **Add Logpoint…** → `x = {x}`.
- **Изменить переменную на лету**: двойной щелчок по значению в панели Variables.
- **Вычислить выражение**: вкладка Debug Console или панель Watch.
- **Программная точка останова**: `__debugbreak();` в коде.

## Магические числа отладочной сборки MSVC

| Значение | Где | Смысл |
|---|---|---|
| `0xCCCCCCCC` (`-858993460`) | стек | неинициализированная переменная |
| `0xCDCDCDCD` (`-842150451`) | куча | выделено, но не заполнено |
| `0xDDDDDDDD` | куча | уже освобождено (use-after-free) |
| `0xFDFDFDFD` | края блока кучи | «ничейная земля»: выход за границу |

## Терминал Developer PowerShell

Выбирается в выпадающем списке рядом с **+** в панели терминала. Полезные команды:

```powershell
cl /std:c++latest /EHsc /utf-8 file.cpp   # скомпилировать вручную
cl /P file.cpp                            # только препроцессор → file.i
cl /O2 /FA /c file.cpp                    # ассемблерный листинг → file.asm
dumpbin /symbols file.obj                 # таблица символов
dumpbin /dependents program.exe           # от каких DLL зависит
lib /list library.lib                     # что внутри статической библиотеки
undname ?square@@YAHH@Z                   # расшифровать декорированное имя
```
